# Project Structure

This document outlines the architecture and directory structure of the **Life Care Plus** platform, which consists of a Next.js frontend (`client`) and a Node.js/Express backend (`server`).

## Root Directory

```text
life-care-plus/
├── client/                 # Next.js frontend application
├── server/                 # Node.js backend API
├── docs/                   # Project documentation
├── docker-compose.yml      # Docker configuration to run the full stack
└── .gitignore              # Git ignore rules for the entire project
```

---

## Client (Frontend)

The frontend is built with **Next.js** using the App Router, TypeScript, and modern UI components.

```text
client/
├── public/                 # Static assets (images, icons, fonts) served directly
├── src/                    # Main source code directory
│   ├── app/                # Next.js App Router core directory
│   │   ├── (auth)/         # Grouped routes for authentication (Login, Register)
│   │   ├── (dashboard)/    # Grouped routes for user dashboards (Admin, Doctor, Patient)
│   │   └── (public)/       # Grouped routes for public-facing pages (Home, About, etc.)
│   │
│   ├── assets/             # Internal assets like SVGs or specific graphics
│   ├── components/         # Reusable React components
│   │   ├── buttons/        # Button variants
│   │   ├── cards/          # Card layouts
│   │   ├── charts/         # Data visualization components
│   │   ├── common/         # Generic common components used across the app
│   │   ├── dialogs/        # Modals and dialog boxes
│   │   ├── layout/         # Layout wrappers (Sidebar, Navbar, Footer)
│   │   ├── table/          # Data tables and generic table structures
│   │   └── ui/             # Core UI elements (e.g., Shadcn UI components)
│   │
│   ├── hooks/              # Custom React hooks
│   ├── lib/                # Utility functions, helpers, and configurations
│   ├── services/           # API integration and data fetching logic
│   └── types/              # TypeScript type definitions and interfaces
│
├── .env.local              # Local environment variables
├── components.json         # UI components configuration
├── next.config.ts          # Next.js configuration
├── tailwind.config.ts      # Tailwind CSS configuration
└── package.json            # Frontend dependencies and scripts
```

---

## Server (Backend)

The backend is built with **Node.js, Express.js**, and uses **Prisma ORM** with PostgreSQL.

```text
server/
├── prisma/                 # Prisma ORM setup
│   ├── schema.prisma       # Database schema definition
│   └── migrations/         # Database migration history
│
├── src/                    # Main source code directory
│   ├── app/                # Application core logic
│   │   ├── errors/         # Global error handlers and custom error classes
│   │   ├── interfaces/     # Global TypeScript interfaces
│   │   ├── middlewares/    # Express middlewares (auth guard, validation, etc.)
│   │   ├── routes/         # Centralized API route definitions
│   │   └── modules/        # Feature-based modular architecture
│   │       ├── admin/      # Admin related logic
│   │       ├── auth/       # Authentication and authorization
│   │       ├── doctor/     # Doctor profile and management
│   │       ├── patient/    # Patient profile and management
│   │       ├── appointment/# Appointment booking system
│   │       ├── payment/    # Payment processing
│   │       ├── log/        # System logs management
│   │       └── ...         # Other modules (review, schedule, specialties, user)
│   │                       # *Each module usually contains its own controller, service, route, and validation.*
│   │
│   ├── config/             # Configuration files (Environment variables, etc.)
│   ├── helpers/            # Reusable helper functions
│   ├── lib/                # Third-party library configurations
│   ├── shared/             # Shared utilities across different modules
│   ├── app.ts              # Express application setup
│   └── server.ts           # Server entry point and database connection
│
├── logs/                   # Application log files (generated by Winston/Pino)
├── uploads/                # User uploaded files (images, documents)
├── .env                    # Environment variables
├── package.json            # Backend dependencies and scripts
└── tsconfig.json           # TypeScript configuration
```
